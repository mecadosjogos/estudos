Reconstruir mídia

Depois de restaurar um backup, os mp3 ficam faltando (só o banco é copiado). Isto enfileira a recompressão a partir do que já está arquivado localmente na máquina do worker — sem baixar nem transcrever nada de novo.

Instalar transcrição (worker)

Prepara uma máquina Windows com GPU pra rodar o worker de transcrição (Whisper) contra este deploy — endereço e credencial já vêm embutidos, só falta rodar.

Baixar pacote completo (.zip) Só o script (.ps1)

Máquina nova, sem nada configurado ainda: o .zip — baixa, extrai, roda scripts\instalar_transcricao.ps1 (ou dê dois cliques em instalar_transcricao.bat) de dentro da pasta extraída. Já tem o repositório clonado nessa máquina: o .ps1 sozinho já serve, só atualiza endereço/credencial — pode rodar de novo a qualquer momento pra puxar uma versão atualizada do script.

Instalar processamento de aula (IA)

Prepara uma máquina Windows sem precisar de GPU pra processar aula e transcrever página de material por um chat do Claude Code (RUNBOOK.md) contra este deploy — nunca a API paga.

Baixar pacote completo (.zip) Só o script (.ps1)

Máquina nova, sem nada configurado ainda: o .zip — baixa, extrai, roda scripts\instalar_processar_aula.ps1 (ou dê dois cliques em instalar_processar_aula.bat). Já tem o repositório clonado: o .ps1 sozinho já serve. Depois de instalado, rode .\processar-aulas.ps1 ou .\transcrever-paginas.ps1 direto — cada um dispara o Claude Code sozinho, sem pedir confirmação.

Instalar narração (TTS)

Serviço de TTS local (Chatterbox), standalone — não fala com este deploy, então não precisa de endereço nem credencial embutidos. Instale na mesma máquina com GPU que já roda a transcrição: é o worker (modo contínuo, worker\run_local.ps1) quem drena a fila de narração sozinho assim que este serviço estiver de pé.

Baixar pacote (.zip)

Baixa, extrai, roda tts-service\instalar.ps1 (ou dê dois cliques em instalar.bat) — baixa PyTorch e o modelo (~4GB) no primeiro uso. Pra subir o serviço depois de instalado: tts-service\iniciar.ps1 (ou iniciar.bat) — fica em primeiro plano em 127.0.0.1:8100 até fechar a janela.
